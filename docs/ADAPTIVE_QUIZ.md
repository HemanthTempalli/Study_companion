# Adaptive Quiz Algorithm

## Overview

The quiz system generates questions adapted to the student's current mastery level, prioritizing weak concepts while reinforcing strong ones.

## Question Generation Pipeline

```
1. Gather mastery data for all concepts
2. Calculate concept weights (inverse mastery → higher weight for weak concepts)
3. Retrieve relevant document chunks for weighted concepts
4. Build AI prompt with context, mastery data, and difficulty calibration
5. Generate questions via Groq LLM (structured JSON output)
6. Parse, validate, and store questions
```

## Mastery-Weighted Concept Selection

```python
# Weak concepts (mastery < 50%) get 3x weight
# Medium concepts (50-80%) get 2x weight
# Strong concepts (>80%) get 1x weight

weight = 3 if mastery < 50 else (2 if mastery < 80 else 1)
```

This ensures weak concepts appear more frequently while still including strong concepts for reinforcement.

## Difficulty Calibration

Questions are generated at a difficulty level based on the student's average mastery:

| Average Mastery | Difficulty | Question Style |
|----------------|-----------|----------------|
| < 40% | EASY | Recognition, basic recall |
| 40-70% | MEDIUM | Application, comparison |
| > 70% | HARD | Analysis, synthesis, edge cases |

## Question Types

### MCQ (Multiple Choice)
- 4 options per question
- One correct answer
- Distractor options generated by the LLM based on common misconceptions
- Graded: binary (correct/incorrect × 100%)

### Open-Ended
- Free-text response
- Evaluated by LLM against correct answer
- Scored 0-100 based on completeness, accuracy, and understanding
- Detailed feedback provided

## Evaluation Algorithm

### MCQ Evaluation
```
score = 100 if user_answer == correct_answer else 0
```

### Open-Ended Evaluation
The LLM evaluates against multiple criteria:
- **Accuracy** (0-40): Factual correctness
- **Completeness** (0-30): Coverage of key points
- **Understanding** (0-30): Depth of comprehension

Total score = accuracy + completeness + understanding

## Mastery Update After Quiz

After each answer, mastery is updated using a weighted moving average:

```python
if evidence_count > 3:
    new_mastery = old_mastery * 0.7 + score * 0.3
else:
    new_mastery = old_mastery * 0.5 + score * 0.5
```

This gives:
- **Established concepts** (>3 evidence points): More weight to accumulated evidence (70/30)
- **New concepts** (≤3 evidence points): More responsive to recent performance (50/50)

## Evidence Trail

Every mastery update is recorded with:
- Date, score, source (quiz/tutor)
- Mastery level before and after
- Rolling window of last 50 data points
